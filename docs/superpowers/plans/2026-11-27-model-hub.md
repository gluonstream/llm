# Model Hub (search/get) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `lmm search` and `lmm get` to find Hugging Face GGUF repos and download/register a model with resume, checksum verification and progress.

**Architecture:** A new stdlib `hub.py` handles the Hugging Face API, file selection and download engine. `config.py` gains a user-model registry merged with built-ins. `cli.py` gains `search`/`get` commands. Tests use a local HTTP server, so no test touches the network or the real state dir.

**Tech Stack:** Python 3 stdlib (`urllib`, `json`, `hashlib`, `http.server` in tests), existing `config`/`render`/`service` modules.

**Spec:** `docs/superpowers/specs/2026-11-27-model-hub-search-get-design.md`

## Global Constraints

- Python 3.9-compatible stdlib only; no `huggingface_hub`, no `hf` CLI.
- Endpoint/service behaviour is unchanged; `get` never starts or stops the server.
- Downloads: `~/.local/share/llm/models/<id>/<filename>`, `.part` resume, sha256 verify, atomic replace.
- Registry: `~/.local/state/llm/models.json`, flat `{id: profile}`.
- Built-in profile ids must never be overwritten.
- Single-file GGUF only; detect `-00001-of-` and refuse with a clear message.
- Tests never hit Hugging Face or port 18081.

## Review Focus

- A selector that matches multiple files must list candidates, never pick one silently.
- A resumed download that gets HTTP 200 must restart from byte 0, not append a full body to a partial file.
- A sha256 mismatch must leave no file at the final path and must remove the poisoned `.part`.
- Registering a model with an alias used by a different id must fail before writing the registry.
- A `get` interrupted by Ctrl-C must leave the `.part` file resumable and must not register the model.

- [ ] **Step 3: Implement parsing and selection**

`parse_spec` splits on the last `:` and requires `owner/name`. `gguf_files` keeps case-insensitive `.gguf`, prefers `lfs.size`/`lfs.sha256`, falls back to `size`/`sha256`. `select_file` matches exact filename, filename without `.gguf`, then case-insensitive substring; raises `HubError` with candidates for zero or multiple matches, and refuses names containing `-00001-of-`. `filter_search` keeps results whose id contains `gguf` or whose tags include `gguf`; returns `(shown, hidden_count)`.

`search_models` calls `https://huggingface.co/api/models` with `search`, `limit`, `sort=downloads`, `direction=-1`, and normalizes to `{id, downloads, likes, gated, tags}`. `model_files` calls `/api/models/<repo>?blobs=true` and returns `gguf_files(siblings)`. Both use one `_get_json` helper raising `HubError` on HTTP/JSON errors, adding the `HF_TOKEN` hint on 401/403.

```python
class DownloadTest(unittest.TestCase):
    def setUp(self):
        self.payload = b"x" * 4096
        self.sha = hashlib.sha256(self.payload).hexdigest()
        self.requests = []
        outer = self

        class Handler(BaseHTTPRequestHandler):
            def do_GET(self):
                outer.requests.append(self.headers.get("Range"))
                start = 0
                range_header = self.headers.get("Range")
                if range_header:
                    start = int(range_header.split("=")[1].split("-")[0])
                body = outer.payload[start:]
                self.send_response(206 if start else 200)
                if start:
                    self.send_header("Content-Range",
                                     "bytes %d-%d/%d" % (start, len(outer.payload) - 1,
                                                         len(outer.payload)))
                self.send_header("Content-Length", str(len(body)))
                self.end_headers()
                self.wfile.write(body)

        self.server = HTTPServer(("127.0.0.1", 0), Handler)
        self.base = "http://127.0.0.1:%d" % self.server.server_port
        self.thread = threading.Thread(target=self.server.serve_forever, daemon=True)
        self.thread.start()

    def tearDown(self):
        self.server.shutdown()
        self.server.server_close()

    def test_full_download_and_checksum(self):
        with tempfile.TemporaryDirectory() as tmp:
            dest = Path(tmp)
            path = hub.download_file("owner/repo", {"name": "m.gguf",
                                                   "size": len(self.payload),
                                                   "sha256": self.sha},
                                     dest, base_url=self.base)
            self.assertEqual(path.read_bytes(), self.payload)

    def test_resume_sends_range_and_appends(self):
        with tempfile.TemporaryDirectory() as tmp:
            dest = Path(tmp)
            (dest / "m.gguf.part").write_bytes(self.payload[:1000])
            path = hub.download_file("owner/repo", {"name": "m.gguf",
                                                   "size": len(self.payload),
                                                   "sha256": self.sha},
                                     dest, base_url=self.base)
            self.assertEqual(path.read_bytes(), self.payload)
            self.assertTrue(any(value for value in self.requests))

    def test_checksum_mismatch_leaves_no_final_file(self):
        with tempfile.TemporaryDirectory() as tmp:
            dest = Path(tmp)
            with self.assertRaises(hub.HubError):
                hub.download_file("owner/repo", {"name": "m.gguf",
                                                "size": len(self.payload),
                                                "sha256": "0" * 64},
                                  dest, base_url=self.base)
            self.assertFalse((dest / "m.gguf").exists())
            self.assertFalse((dest / "m.gguf.part").exists())

    def test_existing_valid_file_is_a_no_op(self):
        with tempfile.TemporaryDirectory() as tmp:
            dest = Path(tmp)
            (dest / "m.gguf").write_bytes(self.payload)
            path = hub.download_file("owner/repo", {"name": "m.gguf",
                                                   "size": len(self.payload),
                                                   "sha256": self.sha},
                                     dest, base_url=self.base)
            self.assertEqual(path.read_bytes(), self.payload)
            self.assertEqual(self.requests, [])
```
